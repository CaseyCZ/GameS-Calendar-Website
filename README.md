Herní Kalendář - IGDB Live
Moderní a přehledný webový kalendář herních vydání napojený na IGDB API. Aplikace slouží k rychlému přehledu nadcházejících herních titulů, filtrování podle platforem a sledování data vydání s vizuálně přitažlivým rozhraním.

🚀 Hlavní funkce
Přehledný kalendář vydání: Seskupení her podle dnů, týdnů či měsíců.

Filtrování platforem: Rychlé přepínání a filtrování her podle herních platform (PC, PlayStation, Xbox, Nintendo atd.) pomocí vizuálních ikon.

Detailní karty her: Zobrazení obalů her (cover art), vývojářů, žánrů a přesných dat vydání.

Responzivní design: Moderní uživatelské rozhraní navržené pomocí HTML a Tailwind CSS, optimalizované pro desktop i mobilní zařízení.

Živá data: Automatické načítání aktuálních a ověřených informací přímo z IGDB databáze.

🛠️ Použité technologie
Frontend: HTML5, Tailwind CSS

Zdroj dat: IGDB API (Internet Game Database)

Správa kódu: Git / GitHub
